# Cortex Local Demo V3

Frontend-only local demo with three screens:

- `/` — Dashboard
- `/focus/plan` — ultra-detailed task decomposition
- `/focus` — single-step Focus Mode

Run:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The Dashboard demo button routes to the detailed breakdown screen.  
The breakdown screen turns a vague hard task into 16 tiny micro-steps, with only the first step actionable.  
Starting the first step opens Focus Mode.

No backend, API, database, or real AI is connected.
